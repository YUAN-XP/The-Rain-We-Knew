# ProjectMystery 全 Demo 美术一致性约束 · 2026-09-21

本文件依据最新用户确认；旧版油腻写实环境及此前 Scene01 雨夜参考不再作为生产风格母版。

## 共用画法

- 现代中国生活环境，2005 年以后；正常场景使用维护中的住宅、现代空调、铝窗、公告、便利店货架和校园设施，不刻意制造八九十年代。
- 哑光纸绘、克制的石墨轮廓、柔和色块和少量材质笔触。拒绝锐化光边、塑料高光、全画面颗粒堆砌。
- 人物优先于背景。远景降低细节与对比；交互高亮沿现有近距离焦点出现，不能将所有道具同时高亮。
- 暖色场景以杏黄、橙、蓝和自然绿展开；恐怖场景以冷青、灰紫、黑色及局部不安光变化。材质仍用同一种画法，不用全屏染黑代替恐怖设计。

## 共用空间与身份

- Scene02/03 是同一所房子的两种状态，门、楼梯、房间、客厅内部关系和游戏落点保持一致。
- 里世界有真实的受潮、磨损、剥落与不自然的静止感；正常回忆保留生活痕迹而非过度复古。
- 成年肖鹏和邱天的现有身份稿保留。肖鹏各年龄眼角痣位于本人左眼外侧（正面观看时画面右侧），立绘检查以源图分辨率为准。
- 邱天各年龄保留有限的脸型与发型连续性，不用完全不同身份替代；成年不加背包。
- NPC 需有年龄、体型、脸型差异。交互 NPC 保留独立裁切键，方便后续字幕立绘。
- 迷宫采用同坐标双布局，墙面对应现有碰撞边；新增装饰不得暗示虚假通路，不得盖住拐角或切换安全区。

## 文件与迭代

- 源图统一位于“美术新”，分类为角色、场景、效果、界面；Unity 使用 Assets/Art/正式，保留既有 Assets/Art/旧。
- 源 PNG 不做破坏性裁切；独立 Visual / SpriteArtRegion / PresentationArtLibrary 记录裁切框、底中 Pivot 与 PPU=256。
- 本轮为首轮环境和角色接入。分页漫画、完整行走奔跑动作、音乐专题与全 UI 皮肤仍按用户安排后置。
- 商用发行前需逐图人工检查生成瑕疵、角色一致性、第三方标识及当前平台披露要求；本轮没有下载或导入第三方游戏素材。

## 本轮参考的用途

用户提供的真实街区照片用于店面经营活动与现代生活设施；《黑羊》截图用于校园前中后景和门洞楼梯的观察。《烟火》的主角可读性、《昏迷》的线稿、《奇异人生》《心跳漏一拍》的情绪手绘语言用于原创方向研究，不复制其人物或场景图。
