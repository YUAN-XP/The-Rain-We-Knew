## 分层素材和骨骼规范

先做成年默认服样板，再扩展到成年另外两套、童年、高中、成年邱天与童年男孩。每套左右素材都记录源 PNG、SHA256、切片、方向及原生像素；当前清单见 11_P02动作矩阵与源图核验.json。

1. 保留头部、脸、痣和发型的有效身份层。大幅转身使用对应方向绘制的头与身体，不能把整人或带痣面部左右翻转。
2. 头颈、发梢、胸腹、骨盆、上臂、前臂、手、大腿、小腿、鞋、必要衣摆分别可控。补足肩、肘、腕、髋、膝等被遮部分，最大允许姿态下不露洞或截断；手与道具不能固定画死在胸前。
3. 左右皮肤使用同一套语义骨骼名和坐标约定。成人三套共用骨长和动作曲线，分别绑定衣物，不用换装改变人物年龄或脚底高度。
4. 根锚点表示地面支撑，另外定义 pelvis、head、hand_camera、hand_lamp、foot_left、foot_right 和接触时段。人物物理碰撞、互动 Feet 和出生点仍沿用 P01，不让动画反写主角位移。
5. 使用骨骼网格、权重及修正贴图处理肩髋和衣物弯曲；身体不能表现为整块贴图旋转。待机有克制呼吸和发梢衣物变化，头部不能夸张上下漂浮。
6. 近镜头按游戏实际像素预算制作，核对实际输出和导入尺寸。成年 1.8、童年 1.35、高中 1.72 世界单位作为当前标定起点；实际人体比例和接触线以 P01 样板为准，不缩放人体来掩盖滑步。
7. 生成或修改图像之前，先总结角色原型、年龄、服装、画风、痣、方向、构图、部件遮挡补画和透明要求。图像编辑使用图像工具；脚本可记录、切片引用、分析和检查，不用程序拼贴冒充补画质量。
8. 保存可编辑的 Unity 原生 SpriteSkin、骨骼、网格、权重、切片元数据、动作配置及源图哈希。源图不得覆盖；修复前在工程 Documentation 内保存带版本的绑定和代码，已失败的预览不能证明新版通过。当前不再等待 Spine，也不导入 spine-unity。

## 动作与移动绑定

走路按接触、下沉、经过、抬升组织两条腿的相位；跑步有独立腾空、躯干倾斜和摆臂曲线。两者不通过简单加速同一个走路动画替代。

用实际可见位移和暂停时钟计算速度，并区分二维迷宫移动、正常走跑、剧情移动和门口重定位。重定位重置上一位置，不能把传送距离加入步幅。阻挡或松手后进入对应方向待机，不能原地继续跑。距离决定步幅相位，速度决定走跑过渡；支撑脚在接触段保持地面稳定，抬脚后再前移。

动作开始与停止应有过渡，头、手、腿不会突然换到不同尺寸。每一个循环至少连续录制三次，检查支撑脚、摆臂、膝肘关节、痣侧别以及衣服和发梢。以连续实机录制和接触时段数据判断，不以一张定点截图判通过。

迷宫八方向分别验收待机、移动和跑步。方向图可按有效相邻姿态共享骨骼，但验收矩阵中的每个方向都必须记录其实际使用的皮肤与动画，不用横向图左右移动代替向上和向下。

## 相机与油灯交接

状态为收起、拿出中、持有、收回中；相机曝光另由原逻辑持有操作锁。库存拥有某物不等于手中显示它。

Q 打开相机时，从背后取出，经手部锚点到拍照姿势，再允许曝光。Space 完成照片或 Q 取消后收回背后，最后隐藏道具。R 使用油灯时同样先取出，再保持手提；R 取消后收回。Q 和 R 互切须先完成旧道具收回，再拿出新道具；快速输入按明确的目标工具处理，不并行启动两条协程。

相机取景、显门、照片提交和灯油充能保持各自原有逻辑所有者。收取动画不能重放物品获得、拍照、显影、消耗燃油或任务事件。暂停冻结动作和道具进度；切房、切年龄、存档恢复、取消或失效均可靠清理。相机待机/动画过渡不得绕过仅自由行动可保存的规则。

灯的身体、手部位置、光源和材质统一由当前动作状态更新。成年三服装左右提灯走跑都检查；童年只制作其适用的相机动作，不添加成年油灯使用能力。

## 同伴跟随

邱天和男孩有独立身份配置、左右待机走跑、实际位移采样及脚底锚点。邱天走来、递证件与跟随使用同一可见人物；男孩的吉他坐姿与离亭行走使用明确动作交接。旧全身、占位手臂、朝向组件和每帧静态覆盖必须逐一停用，不叠两个人物。

跟随目标由玩家方向及合理跟随间距决定；NPC 速度按距离与真实移动选择走或跑，设置迟滞避免每帧切换。玩家停下时允许同伴完成剩余追赶；转身不瞬移越过玩家；通过门时在黑幕回调恢复落脚点和方向。暂停、剧情占用、房间禁入及存档恢复均保留 P01 的所有者规则。

## 必测组合

内部详细矩阵按七种身份/服装展开，见 11_P02动作矩阵与源图核验.json。矩阵的状态数量是验收组合数，不是要求生成同样数量的独立动画文件；每行保留原需求、实际资源和未测/通过结果。

- 三成年服装左右全部基础与持物动作；切换服装前后脚底、身高、方向和单身体不变。
- 童年左右取收相机，迷宫八向和斜向无超速；高中独立走跑待机，身份不被成年换装覆盖。
- 跑步未解锁、已解锁、临时抑制、撞墙、反向、立即停步，以及低帧率情况下动作与实际速度一致。
- Q 取消、Space 曝光后收回、Q→R、R→Q、连续连按、曝光中按 R、工具动画中暂停和过门。
- 邱天递证件、跟随走跑、玩家停步后的追赶、反向、双向门口和冷读档；男孩吉他坐姿与离亭、跟随和恢复。
- P01 卧室、池塘、两世界 Class3_2 原参数不变，左右全跨度复核；身份立绘、互动提示、四槽和暂停锁保持正确。
- 从 Scene01 初始化后的实际操作主链、真实吉他和投篮、追逐及结尾无回退；诊断状态注入与自然输入证据分别标记。
- 编辑器与独立构建，1920×1080 和 2560×1440 近镜头检查；扩展分辨率按共用测试规范实施并明确未测项。

## 经验与防止返工

| 以前出现的问题 | 每次工作都要执行的检查 |
|---|---|
| 修右侧后左侧又出现墙缝 | 任何共用人物变化都复核三个已冻结空间样板，左右完整走一遍；不为修动画重建背景 |
| 分层靠抬家具，最后家具悬空 | 动画支撑只改人物骨骼和锚点，不改家具脚、墙脚和出生点；脚底高度需与碰撞/互动同时核对 |
| 镜头拉近后源图模糊 | 按实际游戏视点检查原生像素和导入上限；骨骼网格不能用低分辨率整人图无限放大 |
| 出现重复手臂或多个人物 | 记录当前 active/enabled/forceRenderingOff 和所有每帧写入者；替换时只留一个身体和一道具 |
| WALK 帧看起来动了，实走不连贯 | 真实速度、支撑脚和三循环录像为通过证据；候选姿态只作参考 |
| 改默认值但实际实例没改 | 核对 Scene、Prefab、数据资产、运行实例及读档来源；参数统一后复查追逐比例 |
| 验证图重复覆盖导致无法追溯 | 文件名包含 P02 身份、动作、方向、批次；源图SHA、源工程、导出版本、运行画面绑定 |
| 修改多轮仍不见效果 | 同一项两轮失败后停止盲调，先查第二写入者、旧资源、对象层级和重建路径，取得新证据再改 |
