# P02 人物样板：实现审计、问题闭环与验收边界

2026-10-02，最终样板 R13。此记录对应**成年肖鹏、默认服、右向走路/奔跑及起步停止回归**。P02 全阶段仍未完成，尚未 GitHub 提交。样板的内部检查与用户审美验收分开；本记录不能证明其它角色、方向、持物或完整剧情已经通过。

## 实际机制和保留版本

Unity 6000.5.10f1 / 2D Animation 15.1.0。采用混合绑定：袖子是连续的肩肘双骨网格；裤腿是腰根、髋、膝三骨网格；头、躯干、手和鞋按关节锚点刚性运动。不是把整个人拆成硬纸片在每个肘膝处转动，也没有把所有故障都归结为骨骼。

当前 10 个可见原生 SpriteSkin，每件 297 个顶点，共 22 个部件骨骼；12 个源 Sprite 包含跑步手型替换，替换使用同一个手部渲染器。源 PNG 字节未由脚本绘画、拼贴或重采样；切片、轴心、比例、网格权重和运动配置分别留存。

右向近肢为角色本人的右肢，远肢为本人的左肢。近手背面、远手掌面使用各自素材，不整体镜像角色。肖鹏左眼痣的身份规则保留。本轮没有新增服装、剧情或其它动作方向。

修改前 R03 和后续问题版本均保留在工程 Documentation/FirstLargeTest_20261001/P02MotionVersions 中。R13_20261002_062231 保存最终代码、绑定、Prefab、导入元数据和源图 SHA256。旧录像保留作反例，不能证明当前版本通过。

## 同一版本的真实输出

独立运行目录 sample_runs/20261002_062231：正常与四分之一速度原生录像、50 张完整人物关键帧、16 张肩颈腕/髋膝踝近景。正常与慢速来自同一组 Unity 渲染帧，没有用插帧或新图片代替动画。

审核入口为 preview.html；before_after.html 同时显示 R03 与 R13 的真实近似相位对比，并提供所有16张关节近景。browser_playback_review.json 记录已查看的播放范围、关节帧和四个游戏关键帧；R13_browser_review.png 显示最终版本与实际播放器画面，不能用旧页截图替代。

实际记录 3.0117 个完整走路循环和 3.0021 个完整奔跑循环。已在浏览器实际播放正常和 0.25 倍速，并查看全部八个主要相位的上身/下身近景；同时查看完整人物及地面参照。录制初始分配耗时仅发生在站立初始化，循环内最长采样约 0.0534 秒；这不是恒定 60fps 的成片承诺。

独立检查读取蒙皮后的真实顶点和另外读取的源图不透明鞋底，排除透明矩形误判。10 个原生蒙皮、0 个重复蒙皮，未报告坏蒙皮或录像拒帧；鞋底支撑高度约 ±1.5e-8 世界单位，腿端点连接误差小于 9e-8。这些数值支持连接检查，不能单独代替视觉判断。

游戏运行目录 gameplay_runs/20261002_062354：从 Scene01_Rain 启动，使用原 PlayerController/GameplayInput 回放起步、停止、Shift 未解锁、暂停与恢复。18 秒、1306 帧；首段持续移动约 3.158 个完整循环；暂停 63 帧、相位变化 0，未解锁按 Shift 的 138 帧均未错误奔跑。角色始终 10 个可见部件。

游戏录像以原游戏相机渲染 1920×1080 世界画面。它不包含叠加界面，也不是物理键盘焦点测试。临时样板使用走速 1.35，实际稳定水平速度约 1.115；相位依据实际距离，未把配置值冒充真实速度。物理摩擦等差异的根因未在本轮单独审计。

测试后 before_state.json 与 cleanup_state.json 精确核对：原走速 2.2、旧表现启用状态及全部渲染器标志恢复，回放/候选绑定/探针为零，暂停关闭。最后退出 Play Mode。正式场景、Prefab 生产实例和角色控制器未因临时样板测试写入修改。

## 已通过、尚未通过、未验证与不适用

- **已通过本轮内部检查**：右向样板的原头颈露底、髋部凸片、踝缝/鞋底支撑和起步接触问题；独立走跑各三个完整循环、停止回归；临时 Scene01 走路与暂停恢复。结论限定于实际查看的 R13 输出和当前活动范围。
- **尚未通过**：P02 全阶段和用户最终审美验收。R03—R08 的问题输出是失败历史，不能作为交付样板。
- **未验证/未完成**：左向及转向，其它年龄/服装/同伴，完整待机呼吸，持相机/灯与工具切换，剧情解锁后的实机奔跑，生产场景永久集成和统一移速，跨门/读档/追逐/吉他回归，2560×1440 和最终构建。保留原 P01 已验收系统作为回归基准，不能据此声称新版已回归。
- **不适用**：Spine 保存/导出/运行库验收；当前按用户最终决定使用 Unity 原生蒙皮。单一右向样板没有左右镜像验收结果。

本轮只关闭有证据的连接故障。动作是否符合用户希望的沉稳程度、手型和整体气质，由用户查看最新预览判断。不能以“已经改善”宣告完成，也不声称所有可能姿势绝无问题。
